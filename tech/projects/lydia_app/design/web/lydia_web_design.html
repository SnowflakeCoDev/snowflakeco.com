Header & Navigation

Three-tier sticky header: top utility strip (status, location, lang), main row (logo, search, actions), category nav. Cart button uses the brand red as a permanent CTA-color anchor.

Hero Composition

Asymmetric grid: 1fr / 380px. Main hero pairs with two stacked side cards (Discount Card promo + New Arrivals). The Lydia red flows from logo into the primary banner — single brand voice across the fold.

Product Detail

Two-column with vertical thumbnail strip. Price box uses soft gradient + badge for discount visibility. Quad-pillar trust block (origin, delivery, payment, returns) below CTAs.

Cart & Checkout

Sticky summary card (right column) follows scroll. Promo code in dashed-border treatment to read as input zone. Stock-status warnings inline on each row. Total uses largest type for hierarchy.
